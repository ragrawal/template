## 5. Docker packaging

- [x] 5.1 Create `templates/ml/docker/Dockerfile.jinja`: multi-stage `uv`-based build — builder stage runs `uv sync`/builds the wheel, runtime stage copies the installed environment, `webapp/`, and `models/model.pkl`, and runs `CMD [...]`; verify by building the image locally against an overlaid project with a pre-trained `models/model.pkl` and confirming the build succeeds. Done: built successfully via `docker build -f docker/Dockerfile .` against a real overlaid+trained project. Note: the runtime `CMD` ended up as `["uvicorn", "webapp.app:app", "--host", "0.0.0.0", "--port", "8080"]` (not `uv run uvicorn ...`) — the venv's own `uvicorn` is already on `PATH`, and invoking it directly avoids a Python-patch-version mismatch warning `uv run` raised between the builder's and runtime's independently-resolved `python:3.12`-family base images.

Done: verified `docker run --rm <image> find / -xdev -name .git` returns nothing and `/app` contains only `models/`, `src/`, `webapp/`.
